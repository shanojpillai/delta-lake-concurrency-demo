2. Streaming Integration

About Streaming

This page demonstrates Delta Lake's streaming capabilities. The streaming process:

  1. Generates simulated streaming data in real-time
  2. Writes the data to a directory monitored by Spark Structured Streaming
  3. Processes the streaming data and writes it to the Delta table
  4. Demonstrates exactly-once processing and fault tolerance

Use the controls to start and stop the streaming data generator and observe how Delta Lake handles streaming data.

What's Happening Behind the Scenes

The streaming integration process involves several components:

1. Stream Generator
# Generate streaming data python /opt/spark/scripts/stream_generator.py --interval 5 --batch-size 10
2. Structured Streaming Setup
# Read streaming data from the directory streaming_df = spark.readStream \ .format("csv") \ .option("header", "true") \ .schema(schema) \ .option("maxFilesPerTrigger", 2) \ .load(streaming_data_dir) # Add watermark for handling late data streaming_df = streaming_df.withWatermark("Processing_Timestamp", "10 minutes")
3. Write Stream to Delta Table
# Write stream to Delta table delta_query = streaming_df \ .writeStream \ .format("delta") \ .outputMode("append") \ .option("checkpointLocation", checkpoint_dir) \ .trigger(processingTime="5 seconds") \ .start(delta_table_path)
