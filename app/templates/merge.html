4. MERGE Operations

About MERGE

This page demonstrates Delta Lake's MERGE capabilities for upserts. The MERGE operations:

  1. Implement atomic upserts with a single operation
  2. Use conditional logic for updates vs. inserts
  3. Handle schema differences between source and target
  4. Ensure transaction atomicity (all-or-nothing)
  5. Show performance benefits compared to separate operations

Use the controls to generate source data and run MERGE operations to see how Delta Lake handles upserts.

What's Happening Behind the Scenes

The MERGE operation involves several key components:

1. Generate Source Data
# Create a DataFrame with records to update (50% of sample) records_to_update = existing_df.sample(fraction=0.5, seed=42) update_count = records_to_update.count() # Modify the records to update records_to_update = records_to_update \ .withColumn("Sales", col("Sales") * (rand() * 0.4 + 0.8)) # Adjust sales by -20% to +20% .withColumn("Profit", col("Profit") * (rand() * 0.4 + 0.8)) # Adjust profit by -20% to +20% .withColumn("Update_Source", lit("merge_update")) # Create new records (not in the existing data) new_records = template_df \ .withColumn("Order ID", expr("concat('NEW-', uuid())")) # Generate unique Order IDs .withColumn("Update_Source", lit("merge_insert")) # Combine updates and inserts into a single source DataFrame source_df = records_to_update.union(new_records)
2. Perform MERGE Operation
# Perform MERGE operation merge_result = delta_table.alias("target") \ .merge( source_df.alias("source"), "target.`Order ID` = source.`Order ID`" ) \ .whenMatchedUpdate(set={ "Sales": "source.Sales", "Profit": "source.Profit", "Quantity": "source.Quantity", "Update_Source": "source.Update_Source", "Last_Updated": "source.Last_Updated", "Customer_Satisfaction": "source.Customer_Satisfaction" }) \ .whenNotMatchedInsertAll() \ .execute()
3. Conditional MERGE Logic
# Conditional MERGE operation delta_table.alias("target") \ .merge( conditional_source.alias("source"), "target.`Order ID` = source.`Order ID`" ) \ .whenMatchedUpdate( condition="source.Sales > target.Sales", # Only update if sales increased set={ "Sales": "source.Sales", "Profit": "source.Profit", "Update_Source": "'conditional_update_higher'" } ) \ .whenMatchedUpdate( condition="source.Sales <= target.Sales", # Different update for decreased sales set={ "Update_Source": "'conditional_update_lower'" } ) \ .whenNotMatchedInsert( condition="source.Sales > 100", # Only insert if sales > 100 values={ "Order ID": "source.`Order ID`", "Sales": "source.Sales", "Profit": "source.Profit", "Update_Source": "'conditional_insert'" } ) \ .execute()
